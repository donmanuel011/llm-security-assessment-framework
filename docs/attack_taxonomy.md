# Unified Attack Taxonomy

The framework standardizes security threats into 5 top-level categories:

1. **Benign**: Standard user queries, instructions, and non-malicious prompts.
2. **Prompt Injection**: Direct adversarial instructions designed to hijack model system instructions.
3. **Indirect Prompt Injection**: Adversarial instructions hidden within untrusted external context (retrieved web pages, PDFs, emails).
4. **Jailbreak**: Persona adoption, roleplay framing, or prefix injection techniques forcing refusal override.
5. **Prompt Leakage**: Attempts to exfiltrate secret system instructions, developer system prompts, or private memory context.
